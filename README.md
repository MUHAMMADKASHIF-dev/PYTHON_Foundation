# Python Foundation

This is the starting point of my programming career in Python. I created this repository to document my growth, store my practice scripts, and keep track of everything I learn in Python — from beginner exercises to small applied projects.

## Projects

### 🎯 Number Guessing Game
A command-line game where the player tries to guess a randomly generated number between 1 and 100. The game provides "high" or "low" feedback after each guess and tracks the number of attempts taken.

**Concepts practiced:** loops, conditionals, user input validation, random number generation

📁 [`number-guessing-game/`](./number-guessing-game)

---

### 🎯 Hangman
A classic command-line Hangman game where the player guesses letters to reveal a hidden word before running out of attempts.

**Concepts practiced:** loops, string manipulation, conditionals, basic game-state tracking

📁 [`hangman/`](./hangman)
